# Melodia — Landing Page

Landing page para o Melodia, um aplicativo de streaming de música fictício voltado para quem gosta de descobrir novos artistas e quer playlists personalizadas com som de alta qualidade.

Projeto desenvolvido para o CP5 de Front-end Design.

## Estrutura da página

- **Hero Section** — apresentação do app e botão de chamada para ação
- **Apresentação** — principais benefícios do Melodia
- **Funcionalidades** — modo offline, playlists colaborativas e estatísticas de escuta
- **Depoimentos** — avaliações de usuários
- **Formulário de Contato** — captação de e-mails
- **Rodapé** — informações de contato e redes sociais

## Tecnologias utilizadas

- HTML5
- CSS3
- Tailwind CSS
- Font Awesome
- Google Fonts
- JavaScript

## Como visualizar

Basta abrir o arquivo `index.html` em qualquer navegador, ou acessar a página publicada no GitHub Pages.
